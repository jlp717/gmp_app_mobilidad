# Frontend Standards (5.6)

- WCAG 2.2 + axe/Lighthouse por PR + manual tras release mayor (Netguru)
- IA UI riesgo: verifica teclado + screen reader, no solo visual (GreatFrontend)
- Core Web Vitals: LCP<=2.5s INP<=200ms CLS<=0.1 con RUM (Albiorix)
- CSP nonces, nunca unsafe-inline
- Ship menos JS (Miran 2026)
- Revision humana obligatoria incluso para codigo del equipo

Refs: https://www.netguru.com/blog/web-development-best-practices , https://www.greatfrontend.com/blog/senior-frontend-developer-skills
