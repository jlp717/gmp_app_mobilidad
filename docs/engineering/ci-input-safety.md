# Seguridad de entradas de CI

Los valores procedentes de eventos, `workflow_dispatch`, referencias de ramas, outputs entre jobs y matrices se consideran datos no confiables cuando puedan alcanzar `run` o un script de `actions/github-script`. Cada workflow los pasa mediante `env` o `core.getInput`; el shell usa variables entrecomilladas y valida los identificadores que se emplean como referencias Git.

El paso `preflight.check` de `ci-cd.yml` tiene además una plantilla fija: sólo acepta `skip_tests=true` o `skip_tests=false`, falla cualquier otro valor y publica el resultado con `printf`. El checker compara el YAML parseado de ese paso con la plantilla completa. Es deliberado: evita tratar comentarios o fragmentos de shell como evidencia de una validación que no se ejecuta.

`node scripts/quality/workflow-inputs.cjs` analiza todos los YAML de `.github/workflows`. Rechaza cualquier interpolación de GitHub Actions dentro de `run`, `defaults.run` o del campo `with.script`, incluidas funciones y notación con corchetes. Las expresiones permanecen permitidas en `if`, `env` y otros `with`, porque esas posiciones no insertan el dato directamente en código shell o JavaScript. Es un control estático: la revisión humana sigue siendo necesaria para validar el uso posterior de cada variable de entorno.

`ci-self-heal.yml` conserva el disparo manual para consultar metadatos de una ejecución con un identificador entero seguro, entregado al script por entorno. Para un `workflow_run`, usa el identificador del payload. En ambos casos consulta únicamente `getWorkflowRun` y `listJobsForWorkflowRun` en el mismo repositorio, exige SHA hexadecimal de 40 caracteres, repositorio de origen no fork y estado completado. Los permisos globales y cualquier override de job se restringen a `actions: read` y `contents: read`; no se admiten otros clientes de API. No descarga logs, no hace checkout, no ejecuta contenido de la rama fallida y no realiza mutaciones ni comunicaciones externas. El resumen se limita y escapa antes de escribirlo en el resumen de Actions.
